"Amigo de 10" = inteiro N > 10 com I(N) = I(10) = 9/5.

## 2. Enunciados exatos (numeração do paper)

### Teorema 1.1 (Ward 2008, citado como ponto de partida)
Se n é amigo de 10, então n é um quadrado perfeito com pelo menos 6 fatores primos distintos, o menor deles sendo 5. Além disso, existe pelo menos um primo p | n com p ≡ 1 (mod 3) cujo expoente na fatoração de n é ≡ 2 (mod 6); se houver exatamente um primo assim, seu expoente é ≡ 8 (mod 18).

### Teorema 1.2 (resultado principal)
Se N é amigo de 10, então N tem **pelo menos 7 fatores primos distintos** (omega(N) >= 7). Além disso, existem fatores primos p e q de N, **não necessariamente distintos**, tais que p ≡ 1 (mod 10) e q ≡ 1 (mod 6).

### Teorema 1.3
Sejam p, q primos distintos com p^{k-1} || (q - 1) para algum inteiro positivo k. Então p | sigma(q^{2a}) **se e somente se** 2a + 1 ≡ 0 (mod f), onde f é o menor inteiro positivo **ímpar** e **> 1** tal que q^f ≡ 1 (mod p^k).

- Observação de leitura: o enunciado pressupõe implicitamente a existência de tal f. A forma operacional usada no resto do paper é: se NÃO existe ímpar f > 1 com q^f ≡ 1 (mod p^k), então p não divide sigma(q^{2a}) para nenhum a >= 1. Na prova, f acaba sendo a ordem multiplicativa de q mod p^k (que precisa ser ímpar, pois divide o número ímpar 2a+1).
- Notação: f_p^q denota o f do Teorema 1.3 para o par (p, q).

### Corolário 1.4 (ferramenta de "primos forçados")
Sejam p, p*, q três primos distintos com p^{k-1} || (q-1) e (p*)^{k*-1} || (q-1) (k, k* inteiros positivos); suponha p | sigma(q^{2a}) e p* | sigma(q^{2a*}) (a, a* inteiros positivos), com f_p^q e f_{p*}^q como no Teorema 1.3. Se f_{p*}^q | f_p^q, então p·p* | sigma(q^{2a}).
(Em palavras: se p divide sigma(q^{2a}), todo p* cujo f divide f_p^q é forçado a dividir sigma(q^{2a}) também.)

### Corolário 1.5
Seja N amigo de 10 com 5^{2a} || N, a inteiro positivo. Então existe um fator primo p de N tal que 2a + 1 ≡ 0 (mod f) e 5^f ≡ 1 (mod p), onde f é o menor inteiro positivo ímpar maior que 1 **e menor ou igual a min{2a+1, p-1}**.
(A cláusula "f <= min{2a+1, p-1}" é consequência de f | (2a+1) e f | (p-1) = phi(p); no caso q = 5 tem-se q - 1 = 4, e como p >= 7 é ímpar, k = 1 no Teorema 1.3, então a condição é mod p e não mod p^k.)

### Corolário 1.6 (primos de Fermat)
Seja N amigo de 10. Se algum primo de Fermat F_k = 2^{2^k} + 1 (k >= 0 inteiro) divide N, então existe um fator primo p de N com p ≡ 1 (mod 2·F_k).

### Teorema 1.7 (versão sem hipótese de valuação, via resíduo r)
Sejam p e q primos distintos com q > p, e a inteiro positivo. Escreva q ≡ r (mod p) com 1 <= r <= p-1. Então p | sigma(q^{2a}) **se e somente se**:
- caso r != 1: 2a + 1 ≡ 0 (mod f), onde f é o menor inteiro positivo ímpar > 1 tal que r^f ≡ 1 (mod p);
- caso r = 1: 2a + 1 ≡ 0 (mod p).

### Corolário 1.8
Se N é amigo de 10, então N tem um fator primo p ≡ 1 (mod 6).
(Vem de 9 | sigma(N): algum p | N com 3 | sigma(p^{2a_p}); r = p mod 3 = 2 é impossível pois nenhum ímpar f satisfaz 2^f ≡ 1 (mod 3); logo p ≡ 1 (mod 3), e sendo p ímpar, p ≡ 1 (mod 6).)

### Teorema 1.9
Se N = 5^{2a}·m^2 é amigo de 10, com a, m inteiros positivos, então m **não** é livre de quadrados.

### Teorema 1.10
Se N = 5^{2a}·m^2 é amigo de 10, com a, m inteiros positivos (isto é, 5^{2a} || N), então
**Omega(N) >= 2·omega(N) + 6a - 4.**

### Corolário 1.11
Se N = 5^{2a}·m^2 é amigo de 10, com a, m inteiros positivos, e Omega(m) <= K, então
**N < 5·6^{(2^{K-2a+1} - 1)^2}.**
(Na prova aparece a cadeia N < 5·6^{(2^{omega(N)} - 1)^2} < 5·6^{(2^{K-2a+1}-1)^2}.)

### Observações (Remarks) relevantes
- **Remark 3.1:** se N = prod_{i=1}^m p_i^{2a_i} (p_1 = 5) é amigo de 10, então sigma(5^{2a_1}) · prod_{i>=2} sigma(p_i^{2a_i}) = 9 · 5^{2a_1 - 1} · prod_{i>=2} p_i^{2a_i}. Logo (i) para todo p_i existe p_j != p_i com p_i | sigma(p_j^{2a_j}); (ii) os fatores primos de cada sigma(p_i^{2a_i}) pertencem a {3, 5, p_2, ..., p_m}. Esta é a "equação mestra" de todas as eliminações.
- **Remark 3.2:** como 5 | N e 5 = F_1 é primo de Fermat, o Corolário 1.6 dá um fator primo p ≡ 1 (mod 10). Analogamente, se 17 = F_2 | N, então N tem fator primo ≡ 1 (mod 34).
- **Remark 3.3:** no Teorema 1.7 com p = 5 e q > 5: para r em {2,3,4} não existe ímpar f > 1 com r^f ≡ 1 (mod 5); logo 5 | sigma(q^{2l}) força q ≡ 1 (mod 10) e 2l + 1 ≡ 0 (mod 5).
- **Remark 3.4:** se q ≡ 1 (mod 10) então o_5(q) = 1, e se v_5(sigma(q^{2l})) = r então (Lema 2.1) r = v_5(2l+1), logo 2l + 1 ≡ 0 (mod 5^r).
- **Remark 3.5:** o Teorema 1.9 dá o limite trivial Omega(N) >= 2·omega(N) + 2.
- **Remark 3.7:** do Teorema 1.10 seguem Omega(m) >= omega(N) + 2a - 1 (eq. 7) e Omega(m) >= omega(m) + 2a (eq. 8).

### Lemas auxiliares
- **Lema 2.1** (valuação de sigma; de Nielsen/Voight): para primos p, q com q >= 3 e a >= 1:
  v_q(sigma(p^a)) = v_q(p^{o_q(p)} - 1) + v_q(a+1), se o_q(p) | (a+1) e o_q(p) != 1; = v_q(a+1), se o_q(p) = 1; = 0, caso contrário.
- **Lema 2.2:** psi(x) = a·x - a^x é estritamente decrescente em [1, infinito) para todo a > e.
- **Lema 2.3:** se (c_1, ..., c_k) é partição de n (soma dos c_i = n, 1 <= k <= n, c_i >= 1) e a > e é inteiro, então a·n < soma_{i=1}^k a^{c_i}. **[Atenção: como está escrito, é falso no caso-limite em que todos os c_i = 1, quando vale IGUALDADE a·n = soma a^{c_i}; o correto é a·n <= soma a^{c_i}, com igualdade sse todos os c_i = 1. Ver "deslizes" abaixo — não afeta o resultado final.]**
- **Definição 2.4:** M ímpar é "m/d-perfeito ímpar" se sigma(M)/M = m/d.
- **Lema 2.5** (Nielsen 2015): se M é m/d-perfeito ímpar com k fatores primos distintos, então M < d·(d+1)^{(2^k - 1)^2}.
- **Definições combinatórias:** E_q(x) = {p primo ímpar : p | x, q | sigma(p^eta), eta >= 2 par}; A_{n,a}(r) = { soma_{i=1}^r a^{c_i} - r : soma c_i = n, c_i >= 1 }; L_{n,a} = união de A_{n,a}(r) para r = 1..n.
- **Lema 3.6:** o menor elemento de L_{2a-1, 5} é 8a - 4 (atingido pela partição toda de 1's, r = 2a-1). [VERIFICADO-NUMERICAMENTE: a = 1..5, busca exaustiva sobre partições.]

## 3. Métodos de prova

- **Teorema 1.3 / Teorema 1.7:** manipulação elementar de sigma(q^{2a}) = (q^{2a+1} - 1)/(q - 1) e ordens multiplicativas. Para 1.3: p | sigma(q^{2a}) com p^{k-1} || (q-1) força q^{2a+1} ≡ 1 (mod p^k); a ordem f de q mod p^k divide 2a+1 (ímpar), logo f é ímpar e > 1 (f = 1 daria p^k | q-1, contradição). Recíproca por reversão do argumento usando gcd(q-1, p^k) = p^{k-1}. Para 1.7 o mesmo raciocínio é feito com o resíduo r de q mod p, separando o caso degenerado r = 1 (onde sigma(q^{2a}) ≡ 2a+1 mod p).
- **Teorema 1.2:** análise exaustiva de casos supondo omega(N) = 6 (Ward exclui <= 5). Com p_1 = 5 fixo, as restrições de crescimento de I (I(N) < prod p_i/(p_i - 1), monotonicidade) deixam apenas 19 "cadeias" possíveis (p_2, ..., p_6). Cada cadeia é eliminada por: (a) Remark 3.2 — se 17 | N precisa haver primo ≡ 1 (mod 34), que não existe na cadeia; (b) Remark 3.1 — algum primo precisa dividir sigma(5^{2a_1}), mas via Corolário 1.4 isso arrasta um primo companheiro p* (ex.: 11 | sigma(5^{2a}) => 71 | sigma(5^{2a}), pois f_11^5 = f_71^5 = 5; 19 => 829, pois f_19^5 = 9 e f_829^5 = 9) que não pertence à cadeia; (c) comparação exata de frações: I(N) >= I(cadeia com expoentes 2) > 9/5. O Caso 13 (5,7,11,13,29,p_6 com 31 <= p_6 <= 20731) exige congruências combinadas (p_6 ≡ 1, 61 ou 211 (mod 390)) e três tabelas de primos forçados p* para cada p_6 candidato. A parte "p ≡ 1 (mod 10) e q ≡ 1 (mod 6)" segue de Remark 3.2 e Corolário 1.8, sem análise de casos.
- **Corolário 1.6:** por contradição: se nenhum fator primo de N é ≡ 1 (mod F_k), então k* = 1 e f teria que ser divisor ímpar > 1 de phi(F_k) = 2^{2^k}, que não existe; logo F_k não divide nenhum sigma(p^{2a_p}), contradizendo Remark 3.1.
- **Teorema 1.9:** se m fosse livre de quadrados, N = 5^{2a} · prod p_j^2; a equação mestra exige 5 | sigma(p_t^2) para algum t (pois 5^{2a-1} >= 5 divide o lado direito e gcd(5, sigma(5^{2a})) = 1); mas 5 | sigma(p_t^2) exigiria 3 = 2·1 + 1 ≡ 0 (mod 5) (Remarks 3.3/3.4), absurdo.
- **Teorema 1.10:** contabilidade da valuação 5-ádica: 5^{2a-1} tem de se distribuir entre os sigma(p_i^{2gamma_i}) com p_i ≡ 1 (mod 10), e v_5(sigma(p_i^{2gamma_i})) = v_i implica 2gamma_i + 1 ≡ 0 (mod 5^{v_i}), logo 2gamma_i >= 5^{v_i} - 1. Minimizar soma 2gamma_i sujeita a soma v_i = 2a - 1 é minimizar um elemento de L_{2a-1,5}; pelo Lema 3.6 o mínimo é 8a - 4 (partição toda de 1's: 2a - 1 primos distintos ≡ 1 (mod 10), cada um com v_5 = 1 e expoente >= 4). Os demais primos contribuem com expoente >= 2 cada; o balanço dá Omega(N) >= 2·omega(N) + 6a - 4.
- **Corolário 1.11:** de Omega(m) <= K e Remark 3.7 (eq. 7) vem omega(N) <= K - 2a + 1; N é 9/5-perfeito ímpar, e o Lema 2.5 (Nielsen 2015) com d = 5 dá N < 5·6^{(2^{omega(N)} - 1)^2}.

### Deslizes/observações de rigor detectados na leitura (nenhum fatal)
1. **Lema 2.3 com desigualdade estrita:** para a partição toda de 1's vale igualdade a·n = soma a^{c_i} (e.g. 5·1 = 5^1); o enunciado deveria ser "<=". O Lema 3.6 continua correto: o mínimo de L_{2a-1,5} é de fato 8a - 4, ATINGIDO pela partição toda de 1's (verificado exaustivamente para a = 1..5), e portanto a conclusão do Teorema 1.10 não é afetada.
2. **Remark 3.7 (eq. 7) — off-by-one na derivação exibida [DIVERGÊNCIA VERIFICADA
   INDEPENDENTEMENTE nesta Fase 0, no texto v5 via arxiv.org/html/2404.00624v5]:** o
   paper escreve "Ω(5^{2a}) + Ω(m²) = 2a + 2Ω(m) ≥ 2ω(N) + 6a − 4" e conclui a eq. (7)
   "Ω(m) ≥ ω(N) + 2a − 1". Mas a linha exibida dá 2Ω(m) ≥ 2ω(N) + 4a − 4, i.e.
   **Ω(m) ≥ ω(N) + 2a − 2** — um a menos. Não há ganho de paridade (ambos os lados da
   desigualdade de partida são pares), então a eq. (7) exigiria uma melhoria genuína do
   Teorema 1.10 (Ω(N) ≥ 2ω(N) + 6a − 3), que o paper não prova. A eq. (8) e o
   **Corolário 1.11 herdam o problema**: a prova, como escrita ("Since Ω(m) ≤ K, we have
   from (7) that K − 2a + 1 ≥ ω(N)"), sustenta apenas ω(N) ≤ K − 2a + 2 e portanto
   apenas **N < 5·6^{(2^{K−2a+2}−1)²}**. O enunciado original pode ainda ser verdadeiro,
   mas até prova independente o projeto deve usar SOMENTE a versão corrigida (mais

## 4. Fidelidade à tabela do CLAUDE.md

Resumo da tabela (linha #3): "omega(N) >= 7; existem primos p ≡ 1 (mod 10) e q ≡ 1 (mod 6) dividindo N; se 5^{2a} || N, existe primo p | N com 2a+1 ≡ 0 (mod f), onde f é o menor ímpar > 1 com 5^f ≡ 1 (mod p); condição extra se um primo de Fermat divide N; em N = 5^{2a}·m^2, m não é livre de quadrados".

Item a item:

1. **"omega(N) >= 7"** — FIEL (Teorema 1.2).
2. **"existem primos p ≡ 1 (mod 10) e q ≡ 1 (mod 6) dividindo N"** — FIEL, com uma nuance omitida: o paper explicita que p e q **não são necessariamente distintos** (um único primo ≡ 1 (mod 30) poderia cumprir os dois papéis). Como a tabela não afirma distinção, não há erro; mas ao usar a restrição em contagens de primos (e.g. combinar com omega >= 10), NÃO se pode assumir dois primos distintos a partir deste enunciado.
3. **"se 5^{2a} || N, existe primo p | N com 2a+1 ≡ 0 (mod f), onde f é o menor ímpar > 1 com 5^f ≡ 1 (mod p)"** — FIEL (Corolário 1.5). A tabela omite a cláusula do paper "f <= min{2a+1, p-1}", mas essa cláusula é redundante (segue de f | (2a+1) e f | (p-1)); o conteúdo matemático é idêntico.
4. **"condição extra se um primo de Fermat divide N"** — FIEL porém vago; o enunciado exato (Corolário 1.6) é: se o primo de Fermat F_k | N, então N tem fator primo p ≡ 1 (mod 2·F_k). Vale registrar que o item "p ≡ 1 (mod 10)" do item 2 é exatamente este corolário com F_1 = 5.
5. **"em N = 5^{2a}·m^2, m não é livre de quadrados"** — FIEL (Teorema 1.9).

**Divergência (por omissão):** a tabela NÃO menciona dois resultados quantitativos do paper (presentes nas versões v3–v5, jan/2025, e no abstract atual):
- **Teorema 1.10:** Omega(N) >= 2·omega(N) + 6a - 4 (com 5^{2a} || N) — mais forte que o trivial Omega(N) >= 2·omega(N) + 2;
- **Corolário 1.11:** se Omega(m) <= K então N < 5·6^{(2^{K-2a+1}-1)^2} (primeira cota SUPERIOR condicional para um amigo de 10 nesta linha de literatura).
Recomendação: acrescentar ambos à linha #3 da tabela.

Nenhum item da tabela é mais forte do que o que o paper prova (não há exagero); as omissões acima são o único desvio.

## 5. Uso no projeto

**Resultados a re-derivar/verificar (Fase 0–1):**
- Teoremas 1.3 e 1.7 são elementares e curtos — re-derivação completa recomendada; são a base de TODAS as restrições de congruência do nicho. O Lema 2.1 (valuação de sigma) já cobre e generaliza os dois e deve entrar em `core/` com teste exaustivo em faixas pequenas.
- Corolário 1.5 + Remark 3.4 dão restrições fortes sobre o expoente de 5: se v_5(sigma(p^{2gamma})) = r então 2gamma + 1 ≡ 0 (mod 5^r) — expoentes de primos ≡ 1 (mod 10) crescem exponencialmente com a valuação 5-ádica que carregam. Isso é poda direta na busca em árvore da Fase 1 (propagação de divisibilidades por 5·sigma(N) = 9·N).
- Teorema 1.10 e Remark 3.7 são podas de assinatura: dado (omega, a) fixados na árvore, Omega mínimo conhecido; combinar com a cota inferior N > 625·9^{omega(N)-3} (arXiv:2504.08295) e com omega >= 10 (arXiv:2310.15900). Com omega(N) >= 10 e a >= 1, o Teorema 1.10 dá Omega(N) >= 22 já no caso mais fraco.
- Corolário 1.11 merece atenção na Fase 2: é uma cota superior CONDICIONAL (depende de Omega(m) <= K). Cruzá-la com cotas inferiores incondicionais pode eliminar faixas de (a, K): se 5·6^{(2^{K-2a+1}-1)^2} <= cota inferior corrente, então Omega(m) > K é forçado — mais uma restrição estrutural gratuita.

**Técnicas reutilizáveis:**
- **Corolário 1.4 ("primos forçados"):** se p | sigma(q^{2a}) então todo p* com f_{p*}^q | f_p^q também divide sigma(q^{2a}). É uma regra de propagação barata e certificável (só ordens multiplicativas) — implementar como regra de poda genérica na busca da Fase 1 e como gerador automático de tabelas tipo Tabela 1–4 do paper.
- **Equação mestra (Remark 3.1):** os fatores primos de cada sigma(p_i^{2a_i}) têm de pertencer a {3, 5, p_2, ..., p_m} — é o teste de fechamento que elimina quase todas as cadeias. Generaliza imediatamente para amigos de 2p (I(N) = sigma(2p)/(2p) = 3(p+1)/(2p)): a Fase 3 deve tentar formular a versão uniforme em p da equação mestra + Corolário 1.6 (note que 5 ser primo de Fermat é o que dá "p ≡ 1 (mod 10)"; para 2p geral, o análogo depende da fatoração de p-1 e da estrutura de sigma(p^{2a}) — candidato natural a lema uniforme).
- **Contabilidade de valuação (prova do Teorema 1.10):** o esquema "distribuir v_q(lado direito) entre os sigma(p_i^{2gamma_i}) e minimizar soma de expoentes via partições + crescimento q^{v}" é genérico em q; para a família 2p a mesma máquina dá Omega(N) >= 2·omega(N) + (função de v_p) — candidato a resultado uniforme da Fase 3.
- **Aviso metodológico:** a prova do Teorema 1.2 (19 cadeias, tabelas de p*) é exatamente o tipo de análise de casos que nosso projeto quer CERTIFICAR por computação exata reproduzível em vez de confiar em tabelas manuais; os dois deslizes encontrados (Lema 2.3 estrito, typo 381/361) reforçam isso. Script de verificação por amostragem desta leitura: aritmética exata com `fractions.Fraction`, confere Casos 10–12, mínimos de L_{2a-1,5} (a <= 5) e amostra da Tabela 4 — a promover para `experiments/` na Fase 0 se formos usar o Teorema 1.2 como hipótese.
