## 2. Notação e fatos usados pelo paper

- `n` amigo de 10 ⟺ `n ≠ 10` e `I(n) = σ(n)/n = 9/5`.
- Fatos citados (não re-provados aqui): `n` é quadrado perfeito, menor divisor primo 5 (logo `2, 3 ∤ n`) [Ward]; `ω(n) ≥ 10` [Thackeray]. O paper escreve, na prova, `n = 5^{2a_1} · ∏_{2≤i≤ω(n)} q_i^{2a_i}`, com `q_1 = 5 < q_2 < q_3 < …` os divisores primos de `n` em ordem crescente e todos os expoentes pares.
- `q_r` = r-ésimo **menor** divisor primo de `n`; `p_i` = i-ésimo primo (`p_1 = 2, p_2 = 3, p_3 = 5, p_4 = 7, …`); `⌈·⌉` = teto; `log` = logaritmo natural.
- Consequência de `2, 3 ∤ n` e `q_1 = 5`: `q_2 ≥ 7 = p_4`, `q_3 ≥ 11 = p_5`, e em geral `q_j ≥ p_{j+2}` para `j ≥ 2`.

## 3. Enunciados exatos

### Teorema 1.1 (reprodução de [4] = arXiv:2404.05771, Teoremas 1, 2, 3)

Se `n` é amigo de 10 e `q_2, q_3, q_4` são o 2º, 3º e 4º menores divisores primos de `n`, então:

- `7 ≤ q_2 < ⌈7ω(n)/3⌉ · { log(⌈7ω(n)/3⌉) + 2·log log(⌈7ω(n)/3⌉) }`
- `11 ≤ q_3 < ⌈180ω(n)/41⌉ · { log(⌈180ω(n)/41⌉) + 2·log log(⌈180ω(n)/41⌉) }`
- `13 ≤ q_4 < ⌈390ω(n)/47⌉ · { log(⌈390ω(n)/47⌉) + 2·log log(⌈390ω(n)/47⌉) }`

### Teorema 1.2 (resultado principal)

Seja `n` amigo de 10 e `q_r` (com `r ≥ 2`) o r-ésimo menor divisor primo de `n`. Então

`q_r < L · { log L + 2·log(log L) }`,   onde   `L = ⌈A·ω(n)/B⌉`,

para **quaisquer** inteiros positivos `A, B` satisfazendo TODAS as condições:

1. `A/B > 1 / ( (36/25) · ∏_{4≤i≤r+1} (1 − 1/p_i)  −  1 )`
   (o produto percorre os primos `p_4 = 7` até `p_{r+1}`; para `r = 2` o produto é vazio = 1);
2. `gcd(A, B) = 1`;
3. `A/B ∈ Q⁺ \ Z⁺` (i.e. `B ≥ 2`, fração não inteira);
4. `A·B·(r−2) + 2A + B > B²`.

**Forma afiada implícita (só aparece na prova, não no enunciado):** sob as mesmas hipóteses, `q_r < p_L` (o L-ésimo primo). A forma com logaritmos é obtida daí via Teorema 2.1 (Rosser). Para uso computacional, `q_r < p_L` é estritamente mais forte.

### Observação (Remark) 1.1

Como `A > B > 1` (decorrente das condições, no regime em que o limiar da condição 1 é > 1 — ver §5), a condição 4 é redundante para `r ≥ 3`; para `r = 2` ela se reduz a `2A + B > B²`.

### Corolário 1.1 (melhora as constantes de [4] para q_3 e q_4)

Se `n` é amigo de 10:

- `11 ≤ q_3 < ⌈427ω(n)/100⌉ · { log(⌈427ω(n)/100⌉) + 2·log log(⌈427ω(n)/100⌉) }`
- `13 ≤ q_4 < ⌈41ω(n)/5⌉ · { log(⌈41ω(n)/5⌉) + 2·log log(⌈41ω(n)/5⌉) }`

Como `427/100 < 180/41` e `41/5 < 390/47` (verificado exatamente: `427·41 = 17507 > 17500 = 175·100·… ` — ver §5), e a expressão `⌈x⌉(log⌈x⌉ + 2 log log⌈x⌉)` é crescente em `x` para `x > 3`, esses limites são estritamente melhores que os do Teorema 1.1. As margens de melhora são mínimas: `180/41 − 427/100 = 293/4100` e `390/47 − 41/5 = 23/235` no coeficiente de `ω(n)`.

### Propriedades do índice de abundância (Seção 2 do paper; sem numeração de lema)

1. `I` é fracamente multiplicativa: `gcd(F, G) = 1 ⟹ I(FG) = I(F)·I(G)`.
2. Se `α, F ∈ Z⁺` e `α > 1`, então `I(αF) > I(F)`.
3. `I(∏_{i=1}^{n} p_i^{α_i}) = ∏_{i=1}^{n} (Σ_{j=0}^{α_i} p_i^{−j}) = ∏_{i=1}^{n} (p_i^{α_i+1} − 1)/(p_i^{α_i}(p_i − 1))`.
4. Se `p_1, …, p_n` e `q_1, …, q_n` são primos distintos (dentro de cada lista) com `p_i ≤ q_i` para todo `i`, então, para expoentes positivos `l_i`: `I(∏ p_i^{l_i}) ≥ I(∏ q_i^{l_i})` (trocar primos por menores só aumenta o índice).
5. `I(∏_{i=1}^{n} p_i^{α_i}) < ∏_{i=1}^{n} p_i/(p_i − 1)` (estrito).

### Teorema 2.1 (citado de Rosser 1939, [7])

Se `p_n` é o n-ésimo primo, então `p_n < n(log n + 2·log log n)` para `n ≥ 4`.
(O paper garante `L ≥ 4` observando que `A > B` e `ω(n) > 3` implicam `⌈Aω(n)/B⌉ > 3`.)

## 4. Método de prova

**Teorema 1.2** (contradição + monotonia exata):
1. Supõe `q_r ≥ p_L`. Usando `q_2 ≥ p_4, …, q_{r−1} ≥ p_{r+1}` e as Propriedades 4 e 5, majora
   `I(n) < (5/4) · ∏_{4≤j≤r+1} p_j/(p_j−1) · ∏_{r≤i≤ω(n)} p_{L+i−r}/(p_{L+i−r}−1)`.
2. Aplica `p_k/(p_k−1) ≤ k/(k−1)` (equivale a `p_k ≥ k`; o paper credita ao Remark 3.3 de [4]) e telescopa o produto da cauda:
   `∏_{r≤i≤ω(n)} (L+i−r)/(L+i−r−1) = (L+ω(n)−r)/(L−1)`.
3. Prova que `(L+ω(n)−r)/(L−1) < (A+B)/A` para todo `ω(n) ∈ Z⁺`, escrevendo `A = Bk + μ` (`1 ≤ μ ≤ B−1`, `gcd(B,μ)=1`, possível pois `A/B ∉ Z`) e separando dois casos: `B ∤ ω(n)` (controla a parte fracionária `{μω(n)/B} ∈ {1/B, …, (B−1)/B}` e mostra que a função `φ(t) = ((A+B)t + (1−r)B − 1)/(At − B + 1)` é estritamente crescente com limite `(A+B)/A` — a condição 4 é exatamente `φ' > 0`) e `B | ω(n)` (idem com `τ(t) = ((A+B)t − Br)/(At − B)`, crescente automaticamente para `r ≥ 2`, `A > B`).
4. Conclui `I(n) < (5/4) · ∏_{4≤j≤r+1} p_j/(p_j−1) · (1 + B/A)`. A condição 1 dá `1 + B/A < (36/25)·∏_{4≤i≤r+1}(1 − 1/p_i)`, e a identidade exata `(5/4) · ∏ p_j/(p_j−1) · (36/25) · ∏ (1 − 1/p_i) = (5/4)(36/25) = 9/5` fecha a contradição com `I(n) = 9/5`. Logo `q_r < p_L`, e Rosser dá o enunciado.

**Teorema 1.1 (prova alternativa)** — instância de 1.2: `(A,B) = (7,3)` para `q_2` (limiar `25/11`), `(180,41)` para `q_3` (limiar `175/41`), `(390,47)` para `q_4` (limiar `385/47`).

**Corolário 1.1** — instância de 1.2 com frações mais próximas do limiar: `(427,100)` para `q_3` (`427/100 − 175/41 = 7/4100`) e `(41,5)` para `q_4` (`41/5 − 385/47 = 2/235`).

## 5. Verificação independente (aritmética exata, Fraction/sympy)

Limiar da condição 1: `T_r = 1/(X_r − 1)` com `X_r = (36/25) · ∏_{4≤i≤r+1}(1 − 1/p_i)`:

| r | X_r (exato) | X_r − 1 | limiar T_r | escolha do paper |
|---|---|---|---|---|
| 2 | 36/25 | 11/25 | 25/11 ≈ 2.2727 | 7/3 ≈ 2.3333 ✓ |
| 3 | 216/175 | 41/175 | 175/41 ≈ 4.2683 | 427/100 = 4.27 ✓ (e 180/41 ✓) |
| 4 | 432/385 | 47/385 | 385/47 ≈ 8.1915 | 41/5 = 8.2 ✓ (e 390/47 ✓) |
| 5 | 5184/5005 | 179/5005 | 5005/179 ≈ 27.9609 | (nenhuma explícita no paper) |
| 6 | 82944/85085 | **−2141/85085 < 0** | — | — |

Confirmei também a identidade final `(5/4)·∏_{4≤j≤r+1} p_j/(p_j−1) · X_r = 9/5` para r = 2,3,4,5 e todas as comparações de frações acima (script trivial; reproduzir com `fractions.Fraction` + `sympy.prime`).

### ACHADO CRÍTICO: o teorema só entrega limites para 2 ≤ r ≤ 5

`X_r` é estritamente decrescente em `r` (cada fator novo `(1 − 1/p) < 1`) e `X_6 = 82944/85085 < 1`. Logo, para **todo r ≥ 6** o denominador `X_r − 1` da condição 1 é **negativo** e:

- na leitura em que se exige o limiar positivo (leitura pretendida, visível na prova), **não existe** par `(A,B)` admissível — o teorema é vazio para r ≥ 6;
- na leitura literal (`A/B >` número negativo é trivialmente verdadeiro), o enunciado afirmaria limites que **a prova não sustenta**: o passo final precisa de `1 + B/A < X_r`, impossível quando `X_r < 1` (pois `1 + B/A > 1`). Equivalentemente, a parte fixa `(5/4)·∏_{4≤j≤r+1} p_j/(p_j−1) = 9/(5·X_r)` já excede `9/5` para r ≥ 6 (para r = 6 vale `1001·17/(576·16) = 17017/9216 ≈ 1.8465 > 9/5`), então a contradição não fecha por nenhuma escolha de primos da cauda.

Conclusão: apesar do título e do abstract ("upper bounds for **each** of the prime divisors"), o método fornece limites **apenas para q_2, q_3, q_4 e q_5**. A novidade real vs. [4] é: (a) formulação paramétrica unificada em (A,B); (b) constantes ligeiramente melhores para q_3 e q_4 (Corolário 1.1); (c) um limite para **q_5** que não estava em [4] — porém o paper nunca o explicita como corolário (exemplo admissível: `(A,B) = (113,4)`, `113/4 = 28.25 > 5005/179`; para ω(n) = 10 dá `q_5 < p_283 = 1847`). Rótulo desta análise: [PROVADO] a inviabilidade para r ≥ 6 no argumento do paper (aritmética exata + monotonia); não afirmamos que os enunciados para r ≥ 6 sejam falsos — apenas que não estão provados ali (e são vazios/não instanciáveis na leitura pretendida).

### Exemplos numéricos na forma afiada `q_r < p_L` (para ω(n) = 10, o mínimo conhecido)

- r=2, (7,3): L = ⌈70/3⌉ = 24, `q_2 < p_24 = 89`;
- r=3, (427,100): L = 43, `q_3 < p_43 = 191`;
- r=4, (41,5): L = 82, `q_4 < p_82 = 421`;
- r=5, (113,4): L = 283, `q_5 < p_283 = 1847`.
(Os valores com log do enunciado são maiores: ≈131.8, ≈275.7, ≈604.6, ≈2577 respectivamente — aproximações apenas ilustrativas.)

### Erratas/observações menores

- Na prova do Teorema 1.2, "From (3) and (4)" deveria ser "From **(1)** and (4)" — (3) é uma desigualdade intermediária do Caso 1; o que se combina com (4) é a majoração (1) de I(n). Inócuo.
- O Remark 1.1 pressupõe `A > B > 1`; isso decorre das condições apenas quando `T_r > 1`, o que vale no regime útil r ≤ 5 (T_r ≥ 25/11 > 2), mas não é dito explicitamente no enunciado do teorema.
- A Conclusão sugere que, fixado `ω(n) = m`, o Teorema 1.2 limitaria todos os m primos e restaria checar "todas as combinações" — superestimado: sem limites para q_6, …, q_m (e sem limites de expoentes), o espaço de busca continua infinito.
- A Conclusão cita (via OEIS A074902) que um amigo de 10 é `> 10^30` (computacional).

## 6. Fidelidade à tabela do CLAUDE.md

Linha #6 da tabela: *"Limites superiores para TODOS os primos divisores (generalização de #5)"*.

- **Fiel ao que o paper ALEGA** (título/abstract dizem exatamente isso) e correto em chamar de generalização de #5 (= arXiv:2404.05771, aqui referência [4]): o Teorema 1.2 de fato recupera os três teoremas de [4] como instâncias e os melhora para q_3, q_4.

Pela análise exata do §5, só há pares (A,B) admissíveis para **r ∈ {2, 3, 4, 5}**; para r ≥ 6 a condição sobre A/B tem limiar negativo e a prova não fecha. A linha #6 deveria ler algo como: "Família paramétrica de limites superiores para o r-ésimo menor primo divisor, efetiva para 2 ≤ r ≤ 5 (inclui q_5, novo, e constantes melhores p/ q_3, q_4 que #5); para r ≥ 6 o método não se aplica".

## 7. Uso no projeto

**Fase 1 (fronteira computacional):**
- Usar sempre a forma afiada `q_r < p_L` (não a forma com logs) como poda na busca em árvore por assinaturas: com ω(N) fixado no nó, os 5 menores primos ficam confinados a listas finitas exatas (para ω = 10: q_2 ≤ 83, q_3 ≤ 181, q_4 ≤ 419, q_5 ≤ 1846). Tudo em inteiros/racionais exatos — compatível com as regras de rigor.
- Atenção: q_6, …, q_ω continuam sem limite superior por este método; a poda da cauda tem de vir do racional exato `∏ I` (estilo Ward/Nielsen), como já previsto no roteiro.

**Fase 2 (novas restrições):**
- Alvo natural e barato: **estender a r ≥ 6** trocando a majoração fixa `q_j ≥ p_{j+2}` (pior caso) por informação condicional do ramo (se sabemos que q_2 ≥ 11, o produto fixo encolhe e X_r pode voltar a ser > 1 para r maiores). Ou seja: transformar o teorema em rotina de poda dependente do prefixo de primos já fixado — generalização direta e provavelmente publicável se uniformizada.
- Substituir Rosser 1939 por cotas mais finas (Rosser–Schoenfeld 1962: `p_n < n(log n + log log n)` para n ≥ 6; Dusart) melhora as constantes de graça, se a forma com logs for necessária em enunciados.
- Otimizar (A,B): para cada ω, o melhor L é essencialmente o menor inteiro > T_r·ω compatível com as condições 2–4 (para r = 2 a condição `2A + B > B²` limita B pequeno; verifiquei que com ω = 10 não dá para bater L = 24). Ganhos são marginais; prioridade baixa.
- Explicitar e publicar o corolário para q_5 (o paper não o fez) — resultado pequeno, novo e verificável, se ninguém o tiver publicado (checar papers 2025–2026 dos Mandal/Chatterjee antes, regra de novidade).

**Fase 3 (família 2p):**
- O esqueleto da prova é totalmente reutilizável para amigo N de 2p (I(N) = 3(p+1)/(2p)): (i) fatos básicos sobre menor primo; (ii) majoração `I < (parte fixa) · (cauda telescópica (L+ω−r)/(L−1))`; (iii) truque paramétrico (A,B) com os dois casos de divisibilidade `B | ω`. A constante `36/25` vira `(3(p+1)/(2p)) / (parte fixa análoga)`; o mesmo fenômeno de corte (parte fixa excede o índice-alvo a partir de certo r) aparecerá e determinará até qual r o método uniforme alcança — vale formular isso de uma vez para todo p.

**Técnica reutilizável destacada:** o tratamento exato do teto `⌈Aω/B⌉` via `A = Bk + μ` e análise da parte fracionária `{μω/B}`, com monotonia de homografias `φ, τ` até o limite `(A+B)/A` — evita qualquer análise assintótica e mantém tudo em racionais exatos; encaixa no padrão de rigor do projeto.
