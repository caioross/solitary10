### Notação do paper vs. notação do projeto

O paper escreve `sigma_{-1}(n) = sigma(n)/n` para o índice de abundância — é exatamente o nosso `I(n)`. Nesta nota uso `I(n)`. Demais notações coincidem: `v_p(n)` = valuação p-ádica (estendida a racionais por `v_p(m/n) = v_p(m) − v_p(n)`, podendo ser negativa), `ω(n)` = número de primos distintos, `o_n(m)` = ordem multiplicativa de m módulo n. "Nonidentical prime factors" = fatores primos distintos. O paper também define `I(p^∞) := p/(p−1)` (supremo de `I(p^a)`).

## 2. Enunciados exatos (numeração do paper)

### Lema 1 (fatos clássicos sobre I)

Sejam p, q primos e a, b, m, n inteiros positivos.

- **(a)** Se `a < b`, então `(p+1)/p ≤ I(p^a) < I(p^b) < p/(p−1) =: I(p^∞)`.
- **(b)** Se `p > q`, então `I(p^a) < I(q^b)` (para quaisquer a, b ≥ 1).
- **(c)** Se `gcd(m,n) = 1`, então `I(mn) = I(m)·I(n)`.
- **(d)** Se `m | n`, então `I(m) ≤ I(n)`.
- **(e)** Se `m | n` e `I(m) = I(n)`, então `m = n`.

(Enunciado sem prova no paper; (d)+(e) juntos dão a versão estrita que usamos no CLAUDE.md: divisor próprio tem índice estritamente menor.)

### Proposição 2 (restrições básicas)

Seja n um amigo de 10. Então:

- **(a)** n é um quadrado perfeito, `5 | n` e `gcd(n, 6) = 1` (ou seja, n é ímpar e `3 ∤ n`).
- **(b)** `ω(n) ≥ 5`.

**Método de prova:** De `I(n) = 9/5` vem `9n = 5·σ(n)`, logo `5 | n`. Se `2 | n`, então `10 | n` com `I(n) = I(10)`, e o Lema 1(e) força `n = 10`, contradição com a definição de amigo — logo n é ímpar. n ímpar força `σ(n)` ímpar; como `σ(n) ≡ ∏(a_j + 1) (mod 2)`, todos os expoentes a_j são pares, logo n é quadrado. Para excluir 3: se `3 | n`, os limites do Lema 1 forçam exatamente `3^2 || n` e `5^2 || n` (expoentes ≥ 4 estouram 9/5); então `m = n/225` satisfaz `I(m) = (9/5)/((13/9)(31/25)) = 405/403`, o que força `403 = 13·31 | m` e daí `I(m) ≥ I(403) > 405/403`, contradição. Finalmente, `I(n) < I(5^∞)I(7^∞)I(11^∞)I(13^∞) = (5/4)(7/6)(11/10)(13/12) < 9/5` mostra que 4 primos não bastam.

### Observações (Remarks) após a Proposição 2 — relevantes para a Fase 3

Não numeradas, mas estrategicamente importantes:

1. Para perfeitos ímpares os mesmos argumentos dão a forma euleriana `p^a·m^2` com `p ≡ a ≡ 1 (mod 4)` e `ω ≥ 3`.
2. Para amigos n de `2p` com p primo, `p ≥ 7` (i.e. `I(n) = (3/2)(p+1)/p`): apenas conclusões mais fracas — n é ímpar, `p | n`, `ω(n) ≥ 2`; e **se** `p ≡ 1 (mod 4)`, n é quadrado (sem melhora em ω).
3. **Obstrução-chave identificada pelo autor:** para amigos de 10 é fácil provar `3 ∤ n`; para amigos de `2p` com `p ≠ 5`, aparentemente não. É por isso que o problema do 10 é especialmente adequado a busca computacional, e os análogos 14, 15, 20 etc. são mais duros.

### Proposição 3 (cotas para o menor primo desconhecido)

Sejam `ℓ₁, k₁, k` inteiros com `0 ≤ ℓ₁ ≤ k₁ < k`. Seja `n = ∏_{j=1}^{k} p_j^{a_j}` (primos distintos, expoentes positivos), com os primos "desconhecidos" ordenados: `p_{k₁+1} < p_{k₁+2} < … < p_k` (nenhuma ordem é suposta entre os k₁ primeiros). Sejam inteiros `b_j` com `a_j ≥ b_j` para `ℓ₁+1 ≤ j ≤ k₁`. (Na aplicação: primos `p_1..p_{k₁}` conhecidos; expoentes exatos conhecidos só para `p_1..p_{ℓ₁}`; para os demais conhecem-se apenas cotas inferiores `b_j`.) Suponha `t_min ≤ I(n) ≤ t_max` com `t_min, t_max` reais positivos. Defina

```
m = t_min / ( ∏_{j=1}^{ℓ₁} I(p_j^{a_j}) · ∏_{j=ℓ₁+1}^{k₁} I(p_j^∞) )
M = t_max / ( ∏_{j=1}^{ℓ₁} I(p_j^{a_j}) · ∏_{j=ℓ₁+1}^{k₁} I(p_j^{b_j}) )
```

Então:

- **(a)** `M > 1` e `p_{k₁+1} ≥ 1/(M−1)`.
- **(b)** Se `a_{k₁+1} ≥ 2`, então `p_{k₁+1} > B_low := [1/(M−1)] · 8/((2−M)² + 7)`.
- **(c)** Se `m > 1`, então `p_{k₁+1} < B_high := 1 + (k−k₁)/(m−1)`.
- **(d)** Se `k₁+2 ≤ k`, `a_{k₁+1} ≥ 2` e A é real com `1 < A ≤ p_{k₁+1}` e `m(A−1)/A > 1`, então `p_{k₁+2} < g(A) := 1 + (k−k₁−1)/( m(A−1)/A − 1 )`.

**Método de prova:** adaptação do argumento clássico de Cohen–Sorli e Nielsen (2007, seção 6). (a) e (c) comparam I(n) com produtos telescópicos de `I` sobre primos consecutivos. (b) usa `I(p^2) > (1 + 1/(2p))²` mais a desigualdade polinomial `sqrt(1+x) ≤ 1 + x/2 − x²/8 + x³/16` (válida para `x ≥ −1`), escolhida **de propósito como função racional de M para manter aritmética exata no computador** (em vez de `p > 1/(2√M − 2)`); o fator de melhora `8/((2−M)²+7)` é `> 1` quando `1 < M < 3`. (d) encadeia (c) e (b).

### Proposição 4 (valuações de σ(x^a) = (x^{a+1}−1)/(x−1); estilo lifting-the-exponent)

Sejam a inteiro positivo, p primo ímpar, x inteiro com `x > 1` e `p ∤ x`.

- **(a)** Se `p | x−1`, então `v_p((x^{a+1}−1)/(x−1)) = v_p(a+1)`.
- **(b)** Se `p ∤ x−1` e `o_p(x) | a+1`, então `v_p((x^{a+1}−1)/(x−1)) = v_p(x^{o_p(x)} − 1) + v_p(a+1)`.
- **(c)** Se `o_p(x) ∤ a+1`, então `p ∤ (x^{a+1}−1)/(x−1)`. Em particular, se a é par, `p = 5` e `5 ∤ x−1`, então `5 ∤ (x^{a+1}−1)/(x−1)`.

**Método de prova:** binômio de Newton dá `v_p(m^p − 1) = v_p(m−1) + 1` e `v_p(m^r − 1) = v_p(m−1)` para `p ∤ r`, quando `p | m−1`; combinando, `v_p(m^r − 1) = v_p(m−1) + v_p(r)`. Aplicar com `m = x` (parte a) ou `m = x^{o_p(x)}` (parte b; `o_p(x) | p−1` é coprimo com p). O caso particular de (c): se `5 ∤ x−1` então `o_5(x) ∈ {2,4}` é par, e `a+1` é ímpar.

### Proposição 5 (fatores primos de σ(p^a) com ordem prescrita)

Sejam p primo ímpar e a inteiro positivo **par**. Para cada divisor d de `a+1` com `d > 1`, o número `σ(p^a)` tem um fator primo `q_d` tal que `o_{q_d}(p) = d`.

**Método de prova:** `(x^{a+1}−1)/(x−1) = ∏_{d | a+1, d>1} Φ_d(x)` (polinômios ciclotômicos) e o teorema de Bang (1886): `Φ_d(p)` tem fator primo q com ordem de p mod q igual a d, exceto em três casos — `(d,p)=(1,2)`, `(d,p)=(6,2)`, ou (`d=2` e `p+1` potência de 2) — nenhum dos quais ocorre com d e p ímpares (a par ⟹ a+1 ímpar ⟹ todo d | a+1 é ímpar).

### Corolário 6 (NOVO segundo o autor — cota geral de expoente)

Seja n um quadrado ímpar com `ω(n) = k > 1`. Seja r um fator primo de `gcd(n, σ(n))`. Seja c inteiro não negativo tal que

```
Σ_{q primo : q|n, gcd(r, q(q−1)) = 1, o_r(q) | v_q(n)+1}  v_r(q^{o_r(q)} − 1)  ≤  c.
```

Suponha que todo fator primo q de n com `q > r` satisfaz `v_q(I(n)) = 0`. Então

```
v_r(n) ≤ (k−1)² + c − v_r(I(n)).
```

(Atenção: `v_r(I(n))` é a valuação do racional `I(n)` e pode ser negativa — para amigos de 10 e r = 5 ela vale −1, o que soma +1 à cota.)

**Método de prova:** Seja `a = v_r(n)`, `a₋₁ = v_r(I(n))`; então `a + a₋₁ = v_r(σ(n)) = v_r(σ(n/r^a))` se decompõe pela Proposição 4 em contribuições `v_r(v_q(n)+1)` (primos q com `o_r(q) | v_q(n)+1`) mais contribuições `v_r(q^{o_r(q)}−1)` (limitadas por c). Pelo princípio da casa dos pombos generalizado, algum q tem `v_r(v_q(n)+1) ≥ b := ⌈(a + a₋₁ − c)/(k−1)⌉`; se `b ≥ 1`, então `r, r², …, r^b` dividem `v_q(n)+1` e a Proposição 5 produz b fatores primos distintos `q_{r^i}` de `σ(q^{v_q(n)})`, cada um `≡ 1 (mod r^i)`, logo `> r`, logo (pela hipótese `v_{q'}(I(n)) = 0` para primos `q' > r`) cada um divide n. Como esses b primos estão entre os k−1 fatores primos de n diferentes de r, `b ≤ k−1`, o que dá a cota.

### Corolário 7 (NOVO — cota do expoente do 5 para amigos de 10)

Para todo amigo n de 10, se `k = ω(n)`, então **`v_5(n) ≤ (k−1)² + 1`**.

**Método de prova:** Corolário 6 com `r = 5` e `c = 0`. O c = 0 é válido porque n é quadrado (`v_q(n)+1` ímpar para todo q) e, para q com `gcd(5, q(q−1)) = 1`, a ordem `o_5(q) ∈ {2,4}` é par — a soma é vazia. Nota: `v_5(I(n)) = v_5(9/5) = −1` e `v_5(n) ≥ 2` (5 | n e n quadrado). Instâncias usadas: `k = 8 ⟹ v_5(n) ≤ 50`; `k = 9 ⟹ v_5(n) ≤ 65` (como v_5 é par, ≤ 64).

### Lema 8 (clássico; equivalente a [Nielsen 2007, Lemma 11])

Sejam p primo ímpar, a inteiro positivo, y inteiro coprimo com p. A equação `z^{p−1} ≡ 1 (mod p^a)` tem exatamente uma solução z com `z ≡ y (mod p)`, e essa solução satisfaz `z ≡ y^{p^{a−1}} (mod p^a)`.

**Método de prova:** Hensel aplicado a `X^{p−1} − 1 ≡ ∏_{ỹ=1}^{p−1}(X − ỹ) (mod p)`; a fórmula explícita segue da Proposição 4(a).

### Proposição 9 (verificação computacional finita; leve melhora de [Nielsen 2007, Lemma 12] em menos casos)

- Se x é um inteiro coprimo com 31 e `1 < x ≤ 31^14`, então
  `v_31(x^{o_31(x)} − 1) ≤ v_31(x^30 − 1) ≤ ⌈log_31 x⌉ + 1`.
- Se x é um inteiro coprimo com 19531 e `1 < x ≤ 19531^6`, então
  `v_19531(x^{o_19531(x)} − 1) ≤ v_19531(x^19530 − 1) ≤ ⌈log_19531 x⌉ + 1`.

**Método de prova:** pelo Lema 8, para achar x coprimo com p em `(p^{a−1}, p^a]` com `v_p(x^{p−1} − 1) ≥ a` basta checar os números `y^{p^{a−1}} mod p^a` para `y ∈ {2, …, p−1}`. Checagem por computador para `p = 31, a ≤ 15` e `p = 19531, a ≤ 7`. (Relevância: `31 = σ(5²)` e `19531 = σ(5⁶)` são primos; se `v_5(n) = 2` então `31 | n`, e se `v_5(n) = 6` então `19531 | n`.)

### Teorema 10 (resultado principal)

**Todo amigo de 10 tem pelo menos 10 fatores primos distintos.** Ou seja: se `N ≠ 10` e `5·σ(N) = 9·N`, então `ω(N) ≥ 10`.

**Método de prova:** Busca em profundidade (DFS) sobre "cadeias de fatores" (esquema de Nielsen 2007 adaptado), implementada em SageMath, com `t_min = t_max = 9/5`, `S_ignore = (3)` e poda por aritmética exata via Proposição 3. As execuções com `5 ≤ k ≤ 7` eliminam diretamente `ω(n) ∈ {5,6,7}`; as execuções com `k ∈ {8, 9}` usam os Corolários 6 e 7 para limitar `v_5(n)` (e, em dois gargalos, o "primo especial" r com a Proposição 9) e eliminam `ω(n) ∈ {8, 9}`. Nenhuma execução produziu fatoração parcial candidata; junto com a Proposição 2 (ω ≥ 5), segue ω ≥ 10.

## 3. O programa de computador (seção 3 do paper) — detalhes reutilizáveis

Ideia central da propagação ("factor chain"): se `v_p(n) = a > 0` e q é fator primo de `σ(p^a)` com `v_q(I(n)) ≤ 0`, então `v_q(n) ≥ v_q(σ(n)) > 0`, logo `q | n`. Estado de cada nó da árvore:

- `S_on` = primos "ligados" (fator primo confirmado com expoente **finalizado**: ou exato `v_q(n) = a_q`, ou mínimo `v_q(n) ≥ b_q`);
- `S_off` = primos confirmados como divisores mas com expoente ainda não finalizado (`v_q(n) ≥ b_q`); são subproduto dos on-primes;
- `P` = cota: todo fator primo fora de `S_on ∪ S_off` é `> P`;
- `S_ignore` = primos p com `v_p(I(n)) > 0` (para 10: apenas o 3, pois `I(n) = 9/5 = 3²/5`) — fatores 3 de `σ(p^a)` não forçam `3 | n`;
- `B` = corte acima do qual `p^a` é "grande" (aí o expoente vira apenas cota inferior e o ramo segue com `b_p`).

Poda em cada nó: `M < 1` ⟹ I grande demais, poda; `m > 1` sem primos possíveis no intervalo `(max{P, B_low}, B_high)` ⟹ poda; ao completar k primos, testes finais incluindo a violação do Corolário 6. Expoentes só pares (n é quadrado). Parâmetros das execuções: `P = 4` para `k ≤ 7` e `P = 5` para `k ≥ 8`.

Primo especial r (usado só em 2 execuções, com `(r, log_r L, δ) = (31, 14, 1)` e `(19531, 6, 1)`): nos dois últimos níveis da árvore, em vez de fatorar, usa-se a Proposição 9 (via os dados `L`, `δ` tais que `1 < x ≤ L` coprimo com r implica `v_r(x^{o_r(x)}−1) ≤ ⌈log_r x⌉ + δ`) para estimar por cima o `c` do Corolário 6 e podar quando `v_5(n)` (= a_r no caso r=5... aqui r = 31 ou 19531 e testa-se `a_r`/`b_r > (k−1)² + s`) é grande demais.

### Técnicas reutilizáveis (Fase 1 — replicar e estender rumo a ω ≥ 11)

- A arquitetura on/off primes + S_ignore + cota B + expoentes pares é uma especificação completa e reproduzível do DFS (seção 3 tem pseudocódigo detalhado; o código SageMath está nos arquivos suplementares do arXiv — vale baixar e auditar antes de reimplementar).
- **Mapa dos gargalos para ω ≥ 11 já dado pelo autor:** os casos `v_5(N) ∈ {2, 6, 10, 12, 46}` (σ(5^a) primo). Para atacá-los seriam necessários análogos da Proposição 9 para primos especiais maiores; para `σ(5^46)` (33 dígitos) o método de checagem direta é inviável — **este é um ponto onde teoria nova (cotas de valuação sem busca exaustiva) teria impacto direto**. Também vale explorar a observação do referee (seção 5): os ramos das árvores para v_5 ∈ {10, 12, 46} são amplamente comuns, sugerindo compartilhamento de computação.

### Fase 2 (novas restrições estruturais)

- O **Corolário 6 é uma ferramenta geral**, não específica do 10: vale para qualquer quadrado ímpar n e qualquer primo `r | gcd(n, σ(n))` (com a hipótese `v_q(I(n)) = 0` para primos `q > r` dividindo n — automática para amigos de 10 quando `r ≥ 5`). Tentar aplicá-lo com outros r (outros primos garantidos em N, p.ex. os primos ≡ 1 mod 10 / mod 6 da restrição #3) para obter cotas de expoente adicionais; o custo é estimar o `c` correspondente (para r = 5 o truque foi: ordens mod 5 pares × expoentes+1 ímpares ⟹ c = 0; para outros r isso falha em geral e exige controle de `v_r(q^{o_r(q)}−1)`).

### Fase 3 (família 2p)

- As Remarks após a Proposição 2 são o diagnóstico mais claro na literatura de **por que 10 é especial**: a exclusão fácil de `3 | n`. Qualquer teorema uniforme para 2p precisa ou contornar ou resolver o caso `3 | n` — registrar isso como a obstrução central da Fase 3. Subcaso estruturado: para `p ≡ 1 (mod 4)`, amigos de 2p são quadrados (mesma paridade de σ), o que já dá acesso ao Corolário 6 nessa subfamília.
